# Сайт-визитка «Сайты под ключ: интернет-магазины и маркетплейсы»

Одностраничный статический сайт на Next.js, TypeScript и Tailwind CSS. Базы данных и бэкенда нет: после сборки получается папка `out/` с готовыми HTML, CSS и JS.

## Запуск

```bash
npm install      # один раз
npm run dev      # режим разработки: http://localhost:3000
npm run build    # сборка готового сайта в папку out/
npm run lint     # проверка кода
```

Посмотреть готовую сборку локально: `npx serve out`.

## Где что менять

У сайта три языка: русский по адресу `/`, казахский на `/kk` и английский на `/en`. Переключатель — кнопка с глобусом в шапке, на телефоне тоже.

Данные, одинаковые для всех языков, хранятся в **`config/site.ts`**. Цену достаточно поменять там, и она обновится на всех трёх языках.

| Что | Где в `config/site.ts` |
| --- | --- |
| Номер WhatsApp | `contacts.whatsappPhone`: только цифры без `+`, например `'77011234567'` |
| Email, Telegram, портфолио | `contacts.email`, `contacts.telegram` (без `@`), `contacts.portfolioUrl` |
| Адрес сайта (для SEO) | `siteUrl`: поменяйте после подключения домена |
| Цены пакетов | `packages` (`price.amount`, `from: true` добавляет «от»), `popular: true` отмечает популярный пакет |
| Цена маркетплейса | `marketplacePrice` |
| Цены других сайтов и доп. функций | `otherSites`, `addons` |

Тексты лежат в **`config/content/ru.ts`**, **`kk.ts`** и **`en.ts`**, по одному файлу на язык. Устроены они одинаково: названия и состав пакетов в `packages.items`, маркетплейс в `marketplace`, вопросы в `faq.items`, тексты WhatsApp в полях `message` / `ctaMessage`. Меняя текст, поправьте его во всех трёх файлах.

Сроки («7–10 дней») записаны текстом в каждом языке, поэтому их тоже нужно менять в трёх файлах. Цены внутри текстов (в FAQ и SEO) подставляются из `config/site.ts` автоматически.

Если добавить пакет в `config/site.ts` и забыть перевести его в каком-то языке, сборка остановится и покажет, где именно не хватает перевода.

> Казахский и английский тексты — черновой перевод. Перед публикацией дайте вычитать казахский носителю языка.

При сборке `config/site.ts` проверяется автоматически. Если телефон записан с «+» или пробелами или ссылка не начинается с `https://`, сборка остановится и покажет, что исправить. Если остались незаменённые заглушки, появится предупреждение.

Цвета задаются в `app/globals.css`: индиго `--accent`, коралл `--coral` и соседние переменные.

## Тема оформления

По умолчанию сайт берёт тему с устройства: светлая или тёмная. Кнопка с луной или солнцем в шапке переключает тему вручную, и выбор запоминается в браузере. Если выбрать тему, совпадающую с темой устройства, сайт снова будет следовать за устройством.

## Примеры сайтов (карусель с MacBook)

Сейчас в карусели 9 **концептов дизайна** с пометкой «Концепт дизайна». Когда появятся реальные работы:

1. Сделайте скриншот главной страницы сайта размером 1440×900 (или 2880×1800 для чёткости) и сохраните его в `public/portfolio/` в двух размерах: шириной 960 и 1600 пикселей, лучше в формате `.webp`.
2. Добавьте работу в `portfolio` в `config/site.ts` (название, картинки, `concept: false`, тогда пометка «Концепт» не появится), а тип сайта и описание впишите в `portfolio.items` каждого языка в `config/content/`.
3. Концепты можно удалить из списка или оставить.

Пересоздать скриншоты концептов (исходники лежат в `design/demos/`): `npm run portfolio:capture`.

> Подтверждена только цена «Пробного» (250 000 ₸). Остальные цены черновые: проверьте их перед публикацией.

## Деплой на Vercel

1. Загрузите проект на GitHub.
2. На [vercel.com](https://vercel.com) нажмите **Add New → Project** и выберите репозиторий.
3. Настройки менять не нужно: Vercel сам распознает Next.js. Нажмите **Deploy**.
4. Подключите домен в **Settings → Domains** и впишите его в `siteUrl` в `config/site.ts`.

Заголовки безопасности (защита от встраивания в чужие сайты, CSP и т.д.) заданы в `vercel.json` и применяются автоматически.

Сайт можно разместить на любом статическом хостинге (Netlify, Cloudflare Pages, обычный хостинг): выполните `npm run build` и загрузите содержимое папки `out/`. Заголовки из `vercel.json` на таких хостингах нужно настроить их собственными средствами, в том числе `Content-Type: image/png` для файлов `opengraph-image` (у каждого языка свой), иначе превью ссылки в мессенджерах не покажется.
