# Сайт-визитка «Сайты под ключ: интернет-магазины и маркетплейсы»

Одностраничный статический сайт на Next.js, TypeScript и Tailwind CSS. Базы данных и бэкенда нет: после сборки получается папка `out/` с готовыми HTML, CSS и JS.

## Запуск

```bash
npm install      # один раз
npm run dev      # режим разработки: http://localhost:3000
npm run build    # сборка готового сайта в папку out/
npm run lint     # проверка кода
```

Посмотреть готовую сборку локально: `npx serve out`.

## Где что менять

Все тексты, цены, пакеты и контакты лежат в одном файле **`config/site.ts`**, вёрстку трогать не нужно.

| Что | Где в `config/site.ts` |
| --- | --- |
| Номер WhatsApp | `contacts.whatsappPhone`: только цифры без `+`, например `'77011234567'` |
| Email, Telegram, портфолио | `contacts.email`, `contacts.telegram` (без `@`), `contacts.portfolioUrl` |
| Адрес сайта (для SEO) | `siteUrl`: поменяйте после подключения домена |
| Цены и состав пакетов | `packages.items` (цена в поле `price.amount`, `from: true` добавляет «от») |
| Маркетплейс | `marketplace` |
| Другие типы сайтов | `otherSites.items` |
| Доп. функции | `addons.groups` |
| Тексты в WhatsApp | поля `message` / `ctaMessage` у каждой кнопки |
| FAQ | `faq.items` |

При сборке `config/site.ts` проверяется автоматически. Если телефон записан с «+» или пробелами, или ссылка не начинается с `https://`, сборка остановится и покажет, что исправить. Про незаменённые заглушки выводится предупреждение.

Цвета задаются в `app/globals.css`: индиго `--accent`, коралл `--coral` и соседние переменные.

## Тема оформления

По умолчанию сайт берёт тему с устройства: светлая или тёмная. Кнопка с луной или солнцем в шапке переключает тему вручную, и выбор запоминается в браузере. Если выбрать тему, совпадающую с темой устройства, сайт снова будет следовать за устройством.

## Примеры сайтов (карусель с MacBook)

Сейчас в карусели 9 **концептов дизайна** с пометкой «Концепт дизайна». Когда появятся реальные работы:

1. Сделайте скриншот главной страницы сайта размером 1440×900 (или 2880×1800 для чёткости) и сохраните его в `public/portfolio/` в двух размерах: шириной 960 и 1600 пикселей, лучше в формате `.webp`.
2. Добавьте работу в `portfolio.items` в `config/site.ts` и укажите `concept: false`: тогда пометка «Концепт» не появится.
3. Концепты можно удалить из списка или оставить.

Пересоздать скриншоты концептов (исходники лежат в `design/demos/`): `npm run portfolio:capture`.

> Подтверждена только цена «Пробного» (250 000 ₸). Остальные цены черновые: проверьте их перед публикацией.

## Деплой на Vercel

1. Загрузите проект на GitHub.
2. На [vercel.com](https://vercel.com) нажмите **Add New → Project** и выберите репозиторий.
3. Настройки менять не нужно: Vercel сам распознает Next.js. Нажмите **Deploy**.
4. Подключите домен в **Settings → Domains** и впишите его в `siteUrl` в `config/site.ts`.

Заголовки безопасности (защита от встраивания в чужие сайты, CSP и т.д.) заданы в `vercel.json` и применяются автоматически.

Сайт можно разместить на любом статическом хостинге (Netlify, Cloudflare Pages, обычный хостинг): выполните `npm run build` и загрузите содержимое папки `out/`. Заголовки из `vercel.json` на таких хостингах нужно настроить их собственными средствами, в том числе `Content-Type: image/png` для файла `/opengraph-image`, иначе превью ссылки в мессенджерах не покажется.
